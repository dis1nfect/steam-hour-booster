Steam Hour Booster, step by step

What the booster actually does, how to set it up the first time, and what to do when something goes wrong. No programming knowledge needed.

How it works

Steam doesn't check whether a game is really running on your PC. It just trusts what your Steam client tells its servers. When you launch a game, the client sends a message like "this account is now playing app 730", and Steam counts playtime for as long as that's true.

The booster is a tiny Steam client without any games or windows. It logs in to your account and sends that same "now playing" message for the games you pick. Nothing gets downloaded or launched, so it uses almost no CPU, memory or internet.

Each game is identified by its app ID, the number Steam uses instead of the name. Counter-Strike 2 is 730, Team Fortress 2 is 440, Dota 2 is 570.

Set it up

  1. Check that Node.js is installed

    The booster is a Node.js program. Open PowerShell (press Start, type PowerShell, press Enter) and run:

    PS> node -v
v26.13.0

    Any version number means you're set (it needs 18 or newer). If PowerShell says node isn't recognised, install the LTS version from nodejs.org and open a new PowerShell window.

  2. Go to the booster folder

    Every command below must be run from inside the folder that holds booster.js.

    PS> cd $HOME\Documents\steamhourbooster

  3. Install the Steam library (once)

    This downloads steam-user, the library that speaks Steam's network protocol, into a node_modules folder. It's already done in your folder, but you need to do it again if you copy the booster to another PC.

    PS> npm install

  4. Find the app IDs of your games

    Open the game's page in the Steam store. The number in the address is the app ID:

    store page address
    store.steampowered.com/app/730/CounterStrike_2/

    You can only add hours to games that are on your account. That means games you own, or free games you've added to your library.

  5. Start the booster

    Put your account name after -u, your app IDs (separated by commas, no spaces) after -g, and optionally a custom title after -t:

    PS> node booster.js -u your_username -g 730,440 -t "Boosting hours"

    Use your account name, the one you type to log in. It's not the same as your profile name.

  6. Log in the first time

    The booster asks for your password. Nothing shows while you type, which is normal. Then Steam asks for a Steam Guard code from your email or the Steam mobile app. If you use the app, you can also just tap Approve on your phone.

    first run
    Password for your_username:
[10:41:02 PM] Logging in as your_username...
Steam Guard code from your mobile app (or approve the login in the app): F7K2Q
[10:41:09 PM] Logged in (SteamID 7656119...)
[10:41:09 PM] Boosting 2 game(s) with custom title "Boosting hours":
[10:41:10 PM]   - 730: Counter-Strike 2
[10:41:10 PM]   - 440: Team Fortress 2
Boosting 2 game(s) as "Boosting hours" | 00:00:42  (Ctrl+C to stop)

    The last line updates every second. As long as that timer is running, hours are being added. Leave the window open; you can minimise it.

  7. Stop it

    Click the PowerShell window and press Ctrl+C. The booster stops the games, logs out, and shows how long it ran. Closing the window also works.

Next time: no password needed

After the first login, Steam gives the booster a login token, and it saves that in the .session folder. Next time it logs in with the token, so you won't be asked for your password or a Steam Guard code. The token is renewed automatically.

Keep the .session folder private. Anyone who has the token file can log in to your Steam account. Don't send it to anyone or upload it. To delete it, run node booster.js -u your_username --logout.

Save your settings in a file

To avoid typing the games every time, make a config.json file. Copy the example and open it in Notepad:

PS> copy config.example.json config.json
PS> notepad config.json

Change the values and save:

config.json
{
  "accountName": "your_username",   <- your login name
  "games": [730, 440, 570],         <- app IDs, up to 32
  "customTitle": "Boosting hours",  <- or "" for no title
  "invisible": false,               <- true = appear offline to friends
  "force": false                    <- see "Playing on another PC"
}

The arrows and notes above are only explanations. Don't put them in the real file, or it won't load. JSON doesn't allow comments.

From now on, starting the booster is just:

PS> node booster.js

Options you type on the command line override the file. For example, node booster.js -g 570 boosts only Dota 2 this time.

All options

OptionWhat it does
-u nameSteam account name to log in with.
-g 730,440Games to boost, by app ID. Up to 32, or 31 with a custom title.
-t "text"Custom title friends see as your current game.
--invisibleAppear offline to friends while boosting. Hours still count.
-f, --forceTake the account back if it's playing somewhere else.
-c fileUse a different config file, e.g. one per account.
--logoutDelete the saved login token and exit.
-hShow the built-in help.

Playing on another PC

Steam lets an account play on only one device at a time. If you start a game on your gaming PC while the booster is running, you'll see:

! This account is playing on another device (app 1172470). Waiting for it to stop...

The booster pauses and the timer stops. When you quit your game, it picks up again by itself:

Account is free again, resuming boost.

With --force it does the opposite and kicks the other device off, which will close your game on that PC. Only use it if you'll never play while boosting.

When something goes wrong

Wrong username or passwordType it again. Check that you used the account name, not your profile name.

Unknown app IDsSteam doesn't recognise that number. Check it on the store page.

Questions

Do the games need to be installed?

No. Steam only needs to be told you're playing. The game doesn't have to be on your PC at all.

Can I use Steam normally while it runs?

Yes. You can chat and browse in the normal Steam client at the same time. Only starting a game pauses the booster, as described above.

Does my PC have to stay on?

Yes. Hours count only while the booster is running and connected. If your PC sleeps, it disconnects, and it reconnects when the PC wakes up.

Will I get achievements or card drops?

Card drops for idled time, yes, on games that still have drops left. Achievements no, since the game never actually runs.

Is this allowed?

Idling doesn't get you VAC-banned, because no game is running. It may still go against Steam's subscriber agreement, and some games don't trust idled hours. You use it at your own risk.

Where is my password stored?

Nowhere. It's only sent to Steam during the first login. Afterwards only the login token in .session is kept.
